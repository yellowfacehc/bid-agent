# 招投标信息快速获取 Agent

自动爬取主流招投标官方网站，按关键词搜索并筛选最近 N 天内的招投标项目，输出项目真实链接。

## 功能特性

- **多平台并行搜索**：同时爬取中国政府采购网、全国公共资源交易平台、中国招标投标公共服务平台
- **关键词精准搜索**：支持任意关键词（如"信息化"、"网络安全"、"云计算"等）
- **时间范围过滤**：默认搜索最近 20 天，可自定义天数
- **多格式输出**：控制台表格 / JSON 文件 / HTML 报告
- **自动去重排序**：跨平台去重，按发布日期降序排列
- **反爬虫处理**：随机 User-Agent、请求延迟、自动重试

## 使用方法

### 基本用法

```bash
# 搜索"信息化"相关招投标信息，最近20天，控制台输出
python bid_agent.py -k "信息化" -d 20

# 输出 HTML 报告
python bid_agent.py -k "信息化" -d 20 --output html -o report.html

# 同时输出 JSON + HTML
python bid_agent.py -k "信息化" -d 20 --output all

# 指定平台和页数
python bid_agent.py -k "网络安全" -d 30 --max-pages 5 --platforms ccgp
```

### 命令行参数

| 参数 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| `--keyword` | `-k` | 搜索关键词（必填） | - |
| `--days` | `-d` | 搜索最近多少天 | 20 |
| `--max-pages` | | 每个平台最大爬取页数 | 5 |
| `--platforms` | | 指定平台，逗号分隔 (ccgp,ggzy,cebpub) | 全部 |
| `--output` | | 输出格式 (console/json/html/all) | console |
| `--output-file` | `-o` | 输出文件路径 | 自动生成 |
| `--verbose` | `-v` | 显示详细日志 | 关闭 |

### Python API 调用

```python
from bid_agent import BidAgent

# 创建 Agent (默认启用全部平台)
agent = BidAgent()

# 搜索
items = agent.search(keyword="信息化", days=20, max_pages=5)

# 遍历结果
for item in items:
    print(f"{item.title} | {item.publish_date} | {item.region} | {item.url}")
```

## 数据结构

每条招投标信息包含以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `title` | 项目标题 | 某单位信息化设备采购项目招标公告 |
| `publish_date` | 发布日期 | 2026-08-13 |
| `region` | 地区 | 广东 |
| `category` | 公告类型 | 招标公告 / 中标公告 / 更正公告 |
| `buyer` | 采购人 | 广州市增城区科技工业商务和信息化局 |
| `agency` | 代理机构 | 广东立信达招标采购有限公司 |
| `url` | 公告真实链接 | http://www.ccgp.gov.cn/cggg/... |
| `source` | 数据来源 | 中国政府采购网 |
| `summary` | 摘要 | 一、项目编号：... |

## 支持平台

| 平台 | 代码 | 接口方式 | 状态 |
|------|------|---------|------|
| 中国政府采购网 | `ccgp` | GET / HTML | ✅ 稳定可用 |
| 全国公共资源交易平台 | `ggzy` | POST / JSON | ⚠️ 平台已升级验证码系统，接口暂不可用 |
| 中国招标投标公共服务平台 | `cebpub` | POST / HTML | ⚠️ 新版接口使用DES加密+JS混淆，暂不支持 |

### 平台可用性说明

**中国政府采购网 (ccgp.gov.cn)** 是目前唯一稳定可用的数据源。该平台覆盖全国各级政府机构的采购公告（招标公告、中标公告、更正公告等），数据全面且接口稳定。

**全国公共资源交易平台 (ggzy.gov.cn)** 已升级为 Vue.js + 验证码系统，旧的数据接口 (dealList_find.jsp) 已废弃返回 502，新接口需要验证码 token，暂无法通过简单 HTTP 请求获取数据。

**中国招标投标公共服务平台 (cebpubservice.com)** 新版搜索接口使用 DES 加密 + JS 混淆，搜索结果通过加密的 AJAX 请求加载，getSearch.do 端点仅返回搜索表单页面。

## 技术细节

### 反爬虫策略

- **随机 User-Agent**：每次请求从 UA 池中随机选择
- **请求延迟**：每次请求间 2-5 秒随机延迟
- **自动重试**：请求失败自动重试最多 3 次，递增延迟
- **请求头伪装**：设置 Host、Referer 等必要请求头

### 并行搜索

使用 `ThreadPoolExecutor` 并行搜索多个平台，每个平台独立运行，互不阻塞。单个平台失败不影响其他平台的结果。
